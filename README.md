## ✨ Features

- **Modern UI/UX Design**: Uses deep dark themes combined with vibrant brand colors (Teal, Blue, Purple) to create a premium cinematic feel.
- **Glassmorphism Elements**: Cards and navigation bars feature frosted glass effects with subtle background blurs.
- **Dynamic Mouse Tracker**: An elegant, custom glowing cursor ring that follows the mouse with smooth trailing animations using `requestAnimationFrame`.
- **Typing Effect Animation**: A custom JavaScript-based typing text effect in the Hero Section that dynamically changes the professional title.
- **Fully Responsive**: Flawless layout on desktop, tablet, and mobile devices using Tailwind CSS grid and flex utilities.
- **Scroll Reveals**: Elements smoothly animate into view as you scroll down the page.

## 🛠️ Tech Stack

This project is built using modern web development tools:

- **HTML5 & CSS3**
- **JavaScript (Vanilla)** for DOM manipulation and custom animations.
- **Tailwind CSS (v3.4)** compiled via CLI for utility-first styling and extremely fast performance.
- **PHP** used as the base server-side language for potential future backend integrations.
- **Phosphor Icons** for clean, consistent, and beautiful iconography.
- **Google Fonts** featuring the 'Outfit' font family for a modern typographic hierarchy.

## 🚀 Installation & Local Setup

To run this project locally on your machine:

1. **Clone the repository:**
   ```bash
   git clone https://github.com/anurr23/aboutaan-me.git
   cd aboutaan-me
   ```

2. **Run on a Local Server:**
   Since this project uses PHP, you need a local server environment like XAMPP, Laragon, or macOS built-in Apache.
   Alternatively, you can use PHP's built-in server:
   ```bash
   php -S localhost:8000
   ```
   Then open `http://localhost:8000` in your browser.

3. **Tailwind CSS Compilation (For Development):**
   If you wish to modify the styles, you can recompile the Tailwind CSS by running:
   ```bash
   npx tailwindcss -i assets/css/input.css -o assets/css/tailwind.css --watch
   ```
